SEI Notion

Cada pessoa conecta o próprio Notion. Sem servidor no meio.

1. URL raiz do SEI obrigatório

Endereço base da instalação do SEI da sua instituição. A extensão só funciona nesses sites. O Chrome pede permissão apenas para eles.

Ex.: https://sei.ifmg.edu.br ou com caminho https://www.orgao.gov.br/sei.

2. Conectar o Notion obrigatório

Você usa o seu workspace. Crie um token e cole abaixo. A extensão guarda o token só neste navegador e fala direto com a API do Notion.

  1. Abra notion.so/my-integrations e crie uma integração interna (ou um token de acesso pessoal).
  2. Capacidades: ler, inserir e atualizar conteúdo.
  3. No Notion, abra o banco (database) que vai guardar os processos → ••• → Add connections → escolha a integração. (Com token pessoal isso não é necessário se você já vê o banco.)
  4. Copie o token (começa com ntn_ ou secret_) e cole aqui.

Usado no bloqueio de edição: se duas pessoas abrirem o mesmo processo, a segunda vê quem está editando. Cada navegador tem um identificador próprio.

3. Banco de dados dos processos

Qualquer database serve. O ideal é ter uma propriedade de texto Número SEI. Se não tiver, use Preparar este banco — a extensão cria as colunas que faltam (Número SEI, Tipo de processo, Status, Marcadores, Prazo, URL SEI, Observações e SEI lock).

Checklist: no banco, use Novo → Novo modelo e monte a lista com /tarefa. No popup você escolhe o modelo num seletor, ou escreve os itens na hora. Os itens ficam na página do processo — dá para editar sem alterar o modelo.

Colunas do banco

As colunas mapeadas para os papéis do SEI são obrigatórias e possuem uma ordem fixa no topo: Número SEI, Tipo de processo, Especificação, Marcadores, Prazo, Atribuição, Observações e URL SEI. Colunas adicionais (extras) aparecem depois e podem ser reordenadas usando ↑↓.

4. Banco de dados de Atividades (Kanban)

Opcional / Recomendado: conecte uma database de Atividades para ter um quadro Kanban com drag-and-drop e checklists dentro de cada atividade no popup do processo.

A database de atividades precisa de uma coluna Relação apontando para o seu banco de Processos e uma coluna Status (ou Seleção) para as etapas do Kanban. Você pode usar o botão Preparar este banco para criá-las automaticamente.
